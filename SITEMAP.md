# Sitemap

- `/` - Landing dashboard for RS Autos HN.
- `/inventory` - Inventory browser with server-side URL filters.
- `/inventory/[slug]` - Vehicle transparency detail page with auction/current toggle, public specs, inspection, repair logs, documents, and WhatsApp CTA.
- `/inventory/[slug]/report` - Buyer-facing PDF technical report generated from public listing data only.
- `/importamos-tu-auto` - Guided import quote flow with WhatsApp handoff.
- `/sobre-nosotros` - Transparency, process, trust modules, testimonials, and public/internal data explanation.
- `/contacto` - Contact options, business metadata, response expectations, and WhatsApp CTAs.
- `/api/vin/decode` - NHTSA vPIC VIN decode integration with typed fallback statuses.
- `/api/import-estimate` - Honduras import cost estimate endpoint for lead guidance.
- `/api/analytics` - Lightweight event collection endpoint for clicks, forms, reports, and page views.
- `/sitemap.xml` - Dynamic sitemap for static pages and public inventory detail pages.
- `/robots.txt` - Search crawler policy.
- `/studio` - Sanity Studio route for content management.
